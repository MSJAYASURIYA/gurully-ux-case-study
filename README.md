# Gurully — UX Case Study

## Project Overview
A UX design case study focused on improving the Gurully test preparation app.

## Objective
Improve navigation, content discoverability, and personalisation to create a simpler and more user-centered learning experience.

## Key Focus Areas
- Simplify navigation.
- Make study materials easier to discover.
- Personalise the learning experience.
- Help users identify the next best preparation activity.

## Design Process
1. Understand the problem.
2. Research user needs.
3. Define the key UX challenges.
4. Develop user flows and wireframes.
5. Create UI designs and a prototype.
6. Validate the design.
